Integrity and limits

The JSON stores original JPEG bytes as Base64, the byte count, and SHA-256. Reconstruction verifies the JPEG signature, byte count, and hash before offering the download.

Size note: Base64 adds about 33% overhead. Large files can use substantial browser memory or exceed GitHub or connector limits.
